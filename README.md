# TarifWerk

Arbeitsrepo für die Überarbeitung von [www.tarifwerk.eu](https://www.tarifwerk.eu).

| Ordner/Datei | Inhalt |
| --- | --- |
| [`UMSETZUNG.md`](UMSETZUNG.md) | Prüfergebnis der Live-Seite und vollständiger Umsetzungsplan (was erledigt ist, was Code braucht, was du entscheiden musst) |
| [`brand/`](brand/README.md) | Neues flaches Logo-System: SVG, PNG, Vorschau, Farb- und Einsatzregeln, Generator |
| [`public/`](public) | Austauschdateien mit denselben Pfaden wie auf der Live-Seite (Favicon, App-Icons, OG-Bild, Logo, Manifest) – in den `public/`-Ordner des Webseiten-Projekts kopieren |

Der Quellcode der Webseite selbst ist (noch) nicht in diesem Repo. Wie man ihn freigibt, steht am Ende von [`UMSETZUNG.md`](UMSETZUNG.md#code-freigeben).
